# RAG Document Search

A Streamlit application for asking questions about one or more PDF documents. It extracts the PDF text, splits it into chunks, retrieves the most relevant passages with semantic search, and uses Google Gemini to produce an answer grounded in that retrieved context.

## Features

- Upload and index multiple PDF files in one session
- Local semantic embeddings with `all-MiniLM-L6-v2`
- FAISS vector search over document chunks
- Context-grounded answers generated by Gemini 2.5 Flash
- Chat-style interface with document and chunk statistics
- Clear the conversation while keeping indexed documents available

## How it works

1. PDF text is extracted with `pypdf`.
2. The text is split into overlapping chunks.
3. Each chunk is embedded with Sentence Transformers and stored in a FAISS index.
4. For each question, the app retrieves the seven closest chunks.
5. Gemini answers from the retrieved context only.

## Requirements

- Python 3.10 or newer
- A Google AI Studio API key for Gemini

## Installation

Clone the repository and move into it:

```bash
git clone https://github.com/Gaurav-Rajput-23/rag-doc-search.git
cd rag-doc-search
```

Create and activate a virtual environment:

```bash
python -m venv venv
```

Windows PowerShell:

```powershell
.\venv\Scripts\Activate.ps1
```

macOS/Linux:

```bash
source venv/bin/activate
```

Install the dependencies:

```bash
pip install -r requirements.txt
```

## Configure the API key

Create `.streamlit/secrets.toml` and add your Google AI Studio API key:

```toml
GOOGLE_API_KEY = "your_google_ai_studio_api_key"
```

Keep this file private. It is already excluded from Git by `.gitignore`.

## Run the app

```bash
streamlit run app.py
```

Streamlit will print a local URL, typically `http://localhost:8501`. Open it in your browser, upload PDFs from the sidebar, and ask questions in the chat input.

## Configuration

You can adjust retrieval behavior in `config.py`:

- `EMBEDDING_MODEL_NAME`: Sentence Transformer used to create vectors.
- `CHUNK_SIZE`: Maximum characters in each text chunk (default: `1000`).
- `CHUNK_OVERLAP`: Shared characters between consecutive chunks (default: `300`).

The answer-generation instructions are also defined in `SYSTEM_PROMPT` in `config.py`.

## Notes

- The FAISS index is held in Streamlit session memory and is recreated when the uploaded document set changes.
- This version supports text-based PDFs. Scanned/image-only PDFs need OCR before their content can be searched.
- Model downloads for the embedding model may occur the first time the app processes documents.
